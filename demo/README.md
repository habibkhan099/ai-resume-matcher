# Demo Screenshots

Add your application screenshots here:

- `screenshot.png` - Main interface screenshot
- `results.png` - Results page screenshot
- `demo.gif` - Application demo GIF

## How to Add Screenshots

1. Take screenshots of your application running
2. Optimize images for web (compress for faster loading)
3. Use descriptive filenames
4. Update README.md with correct image paths

## Recommended Tools

- **Screenshot Tools**: Snipping Tool (Windows), Screenshot (macOS), Flameshot (Linux)
- **GIF Creation**: LICEcap, ScreenToGif, GIMP
- **Image Optimization**: TinyPNG, ImageOptim, Squoosh
