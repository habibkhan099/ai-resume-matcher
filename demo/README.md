## 🚀 How to Take Screenshots

### Windows Instructions:
1. **Start your app**: Run `python main.py`
2. **Open browser**: Go to `http://localhost:5000`
3. **Take screenshots**: Use `Windows + Shift + S`
4. **Save files**: Name them as specified above
5. **Add to repository**: Place in this `demo/` folder

### After Taking Screenshots:
1. Save images in this folder with these names:
   - `main-interface.png`
   - `file-upload.png` 
   - `results.png`
   - `mobile-view.png`

2. **Commit and push**:
   ```bash
   git add demo/
   git commit -m "Add: Demo screenshots and application preview"
   git push
   ```

## 📏 Image Specifications

- **Format**: PNG for screenshots, GIF for animations
- **Width**: 1200-1920px (desktop), 375px (mobile)
- **Quality**: High quality but compressed
- **Size**: Keep under 5MB per image
